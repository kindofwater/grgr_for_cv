## 1. 로그인 / 회원가입 (현수)
**논의**
- 이메일 입력 후 enter → 기존 계정이면 비번 입력, 없으면 회원가입으로 흐르는 통합 방식. 이메일 형식 아니면 오류.
- 문제: 이메일을 오타로 잘못 쳐도 회원가입으로 넘어가 사용자가 헷갈림.
- 검증 시점이 enter 단위라 어색함.

**결정**
- 로그인·회원가입 **창을 분리**(UI/UX 개선).
- 검증을 enter → **마우스 포커스 이동(blur) 단위**로 변경.
- 회원가입 폼: 거주지역 **인구순 정렬**, 입학년도 2020까지만 표시·이하 스크롤(**6년 단위**), 학년 6까지 + 재학/휴학/수료/졸업/유예, 글로고래·닉네임 창 좌우 배치 조정. 단과대는 아직 비움.
- 학과·단과대 목록 수급 방식(크롤링/API/수동) 고민 → 학교가 7만+곳이라 **MVP는 고대만**, 이후 확장. **현수 담당**.
- SSO 도입해도 **아이디찾기·가입 시 학교메일 인증은 필요**. 메일 발송은 API 사용(서버리스 가능 여부 현수 확인). 로그아웃 창 개선.

## 2. 근장찾기 페이지
- 칸별 높이 제각각 → **고정 크기 or 태그 3칸 고정 + 빈 태그**로.
- 결과 약 7만 곳 → **페이지네이션에 화살표·10페이지 건너뛰기** 추가.
- 검색 자동완성: 실시간 X, **드롭다운 이름 추천** 방식(초성검색 불필요, 현재 검색 떨림 버그 있음).
- 고급검색 미구현, 색감/디자인은 후순위.

## 3. 공지사항 (경록)
- 작성/수정은 관리자 페이지 없이 **DB(클로드 연결)에서** 처리.
- **패딩 줄이고 글자·제목 키우기**, 자간 조정(강조 사항).
- 공지/안내 제목 분리 불필요(같은 row), 핀 고정은 핀 이모지/별도 표시, 긴급은 빨간색.
- 클릭 시 별도 탭 대신 **펼쳐지는(아코디언) 방식**으로.

## 4. 교환센터 (현수)
- 🐞 **버그 발견**: 7일 열람권이 30일로 떴다가 다시 7일로 돌아가는 등 포인트/열람기한 꼬임 → 재현해서 추후 수정. 열람권 RPC 함수 점검.

## 5. 홈 / 레이아웃 / 반응형 (경록)
- 모바일 **480px 이하 너비 고정**, 그 이상은 좌우 패딩만 확장.
- 포인트/열람권 값 늦게 뜸 → **페이지 로딩 시 미리 가져오기**(클릭 시 렌더 X).
- 카드 없을 때 흰 화면 대신 큰 텍스트 흐르는 안 검토(보류).
- **전 탭 레이아웃을 KLUE식 좌우 여백 컨테이너로 통일**하기로 합의.

## 6. 마이페이지 (경록)
- 포인트내역 ↔ 내가 쓴 리뷰 스크롤 연결은 안 함(따로따로).
- 사용 버튼 **열 정렬** + 버튼에 **시그니처(고래 애니메이션 등)** 부여.
- 7일 열람권 "사용" 버튼은 제거 검토(포인트 클릭 시 교환센터로 이동하므로).

## 7. 리뷰 작성
- 근로학기 선택 시, **이미 작성한 학기는 선택 시점에 빨간색으로 "이미 작성했어요"** 표시(제출 시점 X). 모달 띄울 때 리뷰 정보 미리 로드.
- "기존 리뷰 수정하기" 버튼은 빨간 표시가 있으면 불필요할 수도(도유진 판단).
- 작성 화면에 **뒤로가기/내비 스텝** 추가.
- 안내(글자수·별점 미선택)는 **모달 대신 토스트**(자동 사라짐).
- 반복 입력으로 글자수 채우기 막기는 **지금 말고 나중에**.
