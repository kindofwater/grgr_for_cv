# 근로고래 - 프로젝트 플래닝

---

## 프로젝트 개요

**목표:** 근로장학생이 근로지 리뷰를 읽고 쓸 수 있는 플랫폼
**1차 범위:** 고려대학교 — 국근장(교외 포함) + 학교 자체 근장
**확장 방향:** 서울대, 연세대 등 타 대학 순차 추가
**1차 런칭 목표:** 2학기 근로장학생 모집 전

---

## 미결 결정 사항

### 디자인
- [ ] 시그니처 컬러 확정
- [x] 캐릭터 / 아이콘 확정: 학사모를 쓴 고래
- [ ] 로그인 화면 구성 (예: "현재 N개의 근장 리뷰", 실제 리뷰 예시 등)
- [ ] 전체 디자인 방향 — 디자이너 없으므로 어떻게 진행할지

### 정책
- [x] 비로그인 유저 접근 수준 결정: 개인화 추천은 숨기고 공개 큐레이션만 보여주되 평점/리뷰 정보는 "-"로 표시, 클릭 시 로그인 화면으로 이동
- [ ] 익명 리뷰 정책 — 티오가 적어 반실명이라 나쁜 리뷰 쓰기 어려운 문제
  - 안: 익명 리뷰는 포인트 없음, 단 도움됐어요 일정 수 이상이면 사후 지급
- [ ] 탈퇴 시 리뷰 처리 (삭제 vs 익명 유지) — policy.md에 미정으로 표시됨

### 기술
- [ ] 서버 스택 결정
- [ ] 배포 방식 결정
- [ ] 다른 학교 크롤링 시 해당 학교 계정 필요 여부 확인 → 필요하다면 행정처/장학재단 직접 연락
- [ ] 국근장 지원율 갱신 주기 (실시간은 어렵다고 보고 있음 — 대안 논의 필요)
- [ ] 학교 포털/SSC 공지 크롤링 → 중복 제거 후 DB화 방안

#### 확정된 구현 패턴
- **도움됐어요 버튼 — Optimistic Update 패턴 사용**
  - 클릭 즉시 UI 업데이트 (카운트 변경 + 버튼 상태 토글) → 백그라운드로 API call
  - 성공: 그대로 유지 / 실패: UI rollback + 에러 토스트
  - INSERT = 좋아요, DELETE = 취소 (`review_helpful` 테이블)
  - "내가 눌렀는지" 여부는 페이지 로드 시 `SELECT EXISTS` 로 초기 상태 결정

### 인증 / 사용자

- [ ] 초기 사용자 모집 전략

## 백로그 (후순위)

- 근장 고충 커뮤니티 (전 학교 통합) — 사용자 충분히 모인 후
- 서울대, 연세대 등 타 대학 DB 추가 — 1차 런칭 후
- 단기 근장 별도 지원
- 지역 광고 / 자체 광고 (초창기 단골 식당 등 직접 영업)
- 국근장 외 학교 자체 공지 크롤링 자동화
