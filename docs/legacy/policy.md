# 근로고래 - 정책

---

## 1. 포인트 정책

### 획득
- 리뷰 작성 시 → 15포인트
- 광고 1개 시청 시 → 5포인트 (적립 횟수 제한 없음)

### 차감 / 삭제 정책
- 리뷰 삭제 시 → 획득했던 15포인트 롤백
- 롤백할 포인트가 부족할 경우 → 삭제 불가, 광고 시청 등으로 포인트를 모은 후 삭제 가능
  - "포인트 모으기 / 취소" 선택지 제공
- 리뷰 신고 처리(재제) 시 → 획득했던 15포인트 롤백
- 삭제 시점/열람 여부에 관계없이 무조건 롤백 적용
- **구현 시 주의: 리뷰 삭제는 반드시 트랜잭션으로 처리**
  1. `points` 테이블에 -15 기록 INSERT (`review_id` 아직 유효한 상태)
  2. `reviews` 테이블에서 해당 row DELETE
  - 순서가 바뀌거나 트랜잭션 밖에서 처리하면 포인트만 차감되거나 리뷰만 남는 상황 발생

### 교환 (열람권)
| 교환 항목 | 필요 포인트 |
|------|--------|
| 7일 열람권 | 10포인트 |
| 30일 열람권 | 20포인트 |

### 환불 (열람권)
- **미사용 재고 열람권만** 환불 가능 → 교환에 쓴 포인트 전액 반환 (7일 10P / 30일 20P)
- 이미 사용(활성화)한 열람권은 환불 불가

---

## 2. 열람 정책

- 열람권 보유 시 → 리뷰 전체 열람 가능
- 열람권 미보유 시 → 업무·자기계발·분위기·시간유연성 점수와 추천 점수는 잠금 플레이스홀더로 대체하고, "리뷰 n개 · m%가 이 근무지를 추천합니다" 집계 문장만 표시
- 열람권 미보유 시 → 리뷰 본문은 잠금 플레이스홀더로 대체 (미리보기 없음)
- 비로그인 시 → 공개 큐레이션/공지 레이아웃을 보여주되 개인화 추천은 숨기고, 평점, 리뷰 수, 리뷰 내용은 "-"로 표시
- 비로그인 상태에서 검색/필터/카드/공지/상단 탭 클릭 시 → 로그인 화면으로 이동

---

## 3. 리뷰 작성 정책

- 학기당 1회만 작성 가능
  - 예: 26년 봄학기 근장 리뷰를 이미 작성했다면, 26년 봄학기 다른 근장 리뷰 작성 불가
  - 단, 이전 학기 근장에 대한 리뷰는 작성 가능
- 입학연도 이전 학기 근장 리뷰 작성 불가
- 추천 점수는 0.5~5점으로 입력
- 추천 점수 4점 이상은 "이 근무지를 추천합니다"로 집계
- 목록/상세의 대표 점수는 업무·자기계발·분위기·시간유연성 평균이 아니라 추천 점수 평균으로 표시
- 의견란 50자 이상 필수

---

## 4. 신고 정책

- 리뷰 신고 사유 선택 후 제출
- 신고 처리 결과
  - 리뷰 삭제 처리 시 → 작성자 포인트 사용/회수
  - 무시 처리 시 → 변동 없음
- 추천(도움됐어요) 수가 과다한 리뷰는 관리자 자동 수집 후 검토

### 계정 신고
- 신고 횟수 누적 시 관리자 검토 대상
- 처리 단계: 경고 → 정지 (세부 기준 미정)

---

## 5. 계정 정책

### 회원가입
- 계열, 학년, 입학연도, 학위 과정, 학적 상태 입력 필수
- SSO 학교 아이디 연동 (추후 구현)

### 학년 변경
- 학기 시작(3월 1일 / 9월 1일) 기준 첫 로그인 시 팝업
- "학년/계열에 변경사항이 있으신가요?" → 확인 또는 수정

### 탈퇴
- 탈퇴 시 작성한 리뷰 처리 방식 미정 (삭제 or 익명 유지)
- 탈퇴 시 보유 포인트 소멸

---

## 6. 관리자 정책

- 신고된 리뷰: 삭제 / 무시 처리
- 추천 수 과다 리뷰: 정상 / 삭제 처리
- 신고된 계정: 경고 / 정지 / 무시 처리
- 관리자 계정은 별도 관리 (일반 회원가입 불가)
