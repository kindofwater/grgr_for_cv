# 근무기간 장기·단기 6주 기준

- 날짜: 2026-07-26
- 상태: 합의 및 구현

## 결정

- 학교근장 근무기간이 **42일(6주) 미만이면 단기**, **42일 이상이면 장기**로 분류한다.
- 정확히 6주는 장기다.
- 한 공고에 여러 근무기간 선택지가 있으면 **가장 긴 선택지**를 기준으로 분류한다.
- 시작일과 종료일이 명확하면 양 끝 날짜를 포함한 달력 일수로 계산한다.
- 기간을 계산할 수 없으면 공고가 명시한 `단기`·`장기` 표현을 따른다.
- 기간과 명시 표현이 모두 불명확하면 `unknown`으로 둔다.
- 국가근장은 개별 기간 정보가 없는 학기 단위 명부이므로 기존처럼 전부 장기로 분류한다.

## 적용 지점

1. SSC/KUPID 통합 파서가 `work_period_days`와 `work_duration_type`을 추출한다.
2. 로더는 `work_period_days`가 있으면 모델이 출력한 라벨보다 42일 기준을 우선한다.
3. 기존 데이터는 마이그레이션으로 명시적인 주 단위 기간과 대표공고 감사 이상치를 보정한다.
4. 고급검색 기간 도움말에 6주 기준·복수 기간·국가근장 예외를 표시한다.

## 현재 대표공고 감사

- 학교근장 대표공고: 단기 11개, 장기 93개, 미분류 4개.
- 단기→장기: 국제교육팀 `약 7주 / 약 13주` 선택형 1건.
- 장기→단기: 교직팀 `7/29~8/14` 1건, 국제어학원 한국어센터 `7/5~8/1` 1건.
- `5/9~6/20`처럼 정확히 6주인 공고는 장기를 유지한다.
