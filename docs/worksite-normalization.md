# 근무지 정규화 규칙

학교근로 공고의 `게시 부서`와 `실제 근무 부서`는 다를 수 있다. 근무지 식별은
다음 우선순위를 따른다.

1. 본문에 명시된 실제 근무 부서·근무 장소
2. 공고 제목의 구체적인 팀·센터·학과명
3. 소스가 제공한 회사명·게시 부서명
4. 주소와 연락처는 위 판단을 보조하는 증거로만 사용

## 자동 통합

- `organization_name`에 학교명이 이미 있으므로 학교근로 표시명 앞의
  `고려대학교(본교)`, `고려대학교`, `고려대`는 제거한다.
- 대학 접두어, 대괄호 태그, 대소문자, 연속 공백을 정리한다.
- 같은 조직의 `행정실`과 `행정팀` 표기는 `행정팀`으로 통일한다.
- 운영 DB에서 확인된 별칭만 명시적 별칭 목록으로 통합한다.
- 정규화 키가 같고, 본문에 서로 충돌하는 조직명이 없을 때만 자동 통합한다.

## 자동 분리

- 학부 단과대학과 전문대학원은 별도 근무지다.
- 산하 팀·센터·학장실처럼 실제 근무 조직이 명시되면 상위 행정팀에서 분리한다.
- 같은 건물이어도 조직명이 다르면 합치지 않는다.
- 같은 조직이라도 근무실이 여러 개인 것은 가능하므로 방 번호만으로 분리하지 않는다.

## 연락처와 주소

- 전화번호가 같거나 마지막 한 자리만 다른 것은 같은 대표번호·인접 내선일 수 있다.
  자동 병합 조건으로 사용하지 않는다.
- 정확히 같은 전화번호와 주소는 동일성 점수를 높이는 보조 증거다.
- 조직명이 충돌하면 전화번호·주소가 같아도 자동 병합하지 않고 감사 대상으로 남긴다.

## 현재 명시 규칙

- `경영대학 행정실`, `경영대학 행정팀` → `경영대학행정팀`
- 위 이름으로 게시됐더라도 본문에 `경영전문대학원`이 명시되면
  `경영전문대학원행정팀`
- 위 이름으로 게시됐더라도 본문에 `경영대학 홍보팀/학장실`이 명시되면
  `경영대학 홍보팀·학장실`
- `미디어대학 행정팀` → `미디어대학행정팀`
- `의학도서관` → `의학정보관리팀`

새 별칭은 원문 공고와 기존 DB를 확인하고 회귀 테스트를 추가한 뒤 반영한다.
활성 학교근무지는 `audit_worksite_norm.py`로 정규화 키뿐 아니라 표시명도
검사하며, 접두어가 다시 들어오면 일일 감사에서 실패하도록 한다.
