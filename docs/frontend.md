# 근로고래 - 화면 설계

---

## 인증 흐름 — **적용됨 (2026-06-24 prod 반영, migration 20260624025109)**

> **컷오버 마이그레이션(`20260624025109_auth_rls_cutover.sql`)은 2026-06-24 prod 적용 완료.**
> 자체 `password_hash` 인증(`verify_login`/`register_user` RPC)은 제거됐고, 아래 Supabase Auth 흐름이 live 상태다.

### 인증·세션 흐름 (현재 live)

**초기화 (`supabase.js`)**
- `createClient` 시 `auth: { autoRefreshToken: true, persistSession: true }` 옵션 포함.

**`AuthContext`**
- `supabase.auth.getSession()` 로 초기 세션 로드 + `onAuthStateChange` 구독으로 세션 변화 감지.
- `isLoading` 상태: 세션 확인 완료 전까지 `true` → `App.jsx`의 라우트 게이트가 이 값으로 렌더 보류.
- 세션 확인 후 `profileQueries.fetchMe` + `_wallet()` RPC로 프로필·지갑 하이드레이션 → `mergeUser` 로 컨텍스트에 병합.
- 노출 인터페이스: `{ user, isLoading, mergeUser, logout }`.
- `logout`: `supabase.auth.signOut()`.
- ⚠️ **onAuthStateChange 데드락 주의**: 콜백 '안에서' `supabase` 직접 호출(fetchMe 등)을 하면 GoTrue 내부 lock과 데드락이 발생해 무한 "로딩 중" 상태가 됨. `setTimeout(0)`으로 다음 틱에 실행해야 lock 밖에서 안전하게 처리됨.

**로그인 (`authQueries.signIn`)**
- `supabase.auth.signInWithPassword({ email, password })` 호출.

**회원가입 (`authQueries.signUpUser`)**
- `supabase.auth.signUp({ email, password, options: { data: { university_id, college_name, department_name, track, nickname, admission_year, degree_program, academic_status, grade, region } } })` 호출.
- 서버 트리거 `handle_new_user`가 `raw_user_meta_data`를 읽어 `public.users` 행 자동 생성.
- 이메일 확인(confirm) ON: 가입 직후 이메일 확인 인터스티셜 화면 표시 → 확인 후 로그인 가능.
- 가입 불가 도메인·학교(`signup_enabled=false`) 시 트리거가 예외를 던지고 클라이언트가 에러 처리.

## 전체 화면 목록

---

### 1. 로그인
- SSO 학교 아이디 로그인 버튼
- 서비스 한줄 소개 / 로고
- 회원가입 링크

---

### 2. 회원가입
- 닉네임 입력
- 입학연도 선택
- 학위 과정 선택 (학부생 / 대학원생)
- 학적 상태 선택 (재학 / 휴학 / 수료 / 졸업유예)
- 단과대학 선택 → 학과 선택
- 계열 선택 (학과 기준 자동 선택, 사용자 수정 가능)
  - 학과 선택 시 계열 드롭다운 자동 세팅
  - 자유전공학부 등 매핑 불가 학과는 빈 값으로 표시 → 직접 선택
- 학년 선택
- 완료 버튼

---


### 3. 홈
- 상단 네비게이션 (로고, 근장 찾기, 열람권 교환, 로그인/유저 pill)
- 대형 검색바 (중앙)
- 큐레이션 섹션들 (가로 스크롤 카드)
  - 큐레이션 섹션당 최대 5개 카드 표시
  - 추천 근장 (로그인 시에만 표시)
    - 우대 계열/학년 매칭 + 추천 점수 높은 순 + 리뷰 많은 순 + 조회수 낮은 순
    - 추천 점수 4.0 이상인 근장만 포함
  - 추천 점수 높은 근장
  - 리뷰 많은 근장
  - 많이 찾아본 근장
- 우측 사이드: 공지사항



---

### 4. 근장 찾기 / 검색 결과
- 네비바 "근장 찾기" 클릭 시 진입 → 검색어 없이 전체 목록 기본 표시
- 검색바 (검색 시 결과 실시간 필터링)
- 고급검색 버튼 클릭 시 필터 영역 노출
  - 공통: 근로유형, 모집상태
  - 국가근로 선택 시: 지역, 선호계열, 선호학년
  - 학교근로 선택 시: 기간, 학위 과정, 학적 상태, 최근 리뷰 있음
  - 고급검색하기 버튼을 눌러 조건 적용
- 열람권 없음 상태에서는 정렬을 리뷰 많은순으로 고정
- 결과 수 + 정렬 드롭다운 (최신순/추천 점수순/리뷰많은순)
- 결과 카드 리스트
  - 근장명, 위치, 모집시기, 태그 (학년·계열 우대사항)
  - 4개 항목 컬러 바 + 수치 (업무·자기계발·분위기·시간 유연성)
  - 추천율 %, 리뷰 수
  - 추천 점수 (크게, 0.5~5 추천 점수 평균)
- **빈 상태:** 검색 결과 없을 때 → "검색 결과가 없어요" + 필터 초기화 버튼

---

### 5. 근장 상세
- 근장 기본 정보 (위치, 근로유형, 학위 과정, 학적 상태, 모집 시기)
- 신청하기 버튼 (근장 신청 사이트로 리다이렉트)
- 추천 점수 요약 (대표 점수는 추천 점수 평균, 4개 항목은 별도 표시)
- 추천율 %
- 리뷰 작성 버튼
- 리뷰 목록
  - 작성자 계열·학년, 별점, 업무 내용, 의견
  - 도움됐어요 버튼, 신고 버튼
- 열람권 없을 시: 업무·자기계발·분위기·시간유연성 점수와 추천 점수는 잠금 플레이스홀더로 대체, "리뷰 n개 · m%가 이 근무지를 추천합니다" 문장은 공개, 리뷰 목록은 본문 대신 잠금 플레이스홀더 + "열람권이 필요해요" 유도 메시지
- **빈 상태:** 리뷰가 아직 없을 때 → "첫 번째 리뷰를 작성해보세요" + 리뷰 작성 버튼

---

### 6. 리뷰 작성
- 근장명 표시
- 4개 항목 별점 선택 (업무·자기계발·분위기·시간 유연성)
- 추천 점수 0.5~5점 선택 (4점 이상이면 "이 근무지를 추천합니다"로 집계)
- 실제 업무 내용 텍스트 입력
- 의견 텍스트 입력 (50자 이상 카운터)
- 제출 버튼
- 해당 학기 근로장학생 리뷰 이미 작성 시 → 해당 학기는 작성 불가 안내(근로장학생은 1학기에 1번 할 수 있기 때문, 26년 봄학기에 관한 근로장학생 리뷰를 작성했다면, 26년 봄학기 다른 곳 근장에 대한 리뷰를 작성할 수 없음, 대신 그 전의 학기 근로장학에 대한 리뷰는 작성가능 + 입학연도 이전의 근로장학생 리뷰도 작성 불가.)

---

### 7. 교환센터
- 포인트 Tip 안내 (획득/사용 조건)
- 현재 보유 포인트
- 현재 열람권 상태(1시간/7일/30일 재고·만료일)
- 열람권 교환 항목 + 교환하기/사용하기/미사용권 환불. 각 상품 가격보다 포인트가 적으면 교환 버튼 비활성
- 닉네임 변경: 20P. 재고로 보관하지 않고 `교환하기`에서 즉시 변경 절차 시작
  - 20P 미만이면 교환 버튼 비활성
  - `20P 사용 확인 → 현재 비밀번호 확인 → 새 닉네임 입력`의 3개 모달이며 각 단계에서 취소 가능
  - 최종 성공 시에만 `change_nickname` RPC 한 번으로 20P 차감·닉네임 변경·원장·변경 이력을 원자 처리
- 광고 보고 포인트 받기 버튼

---

### 8. 마이페이지
- 사이드바: 닉네임, 보유 포인트·열람 가능 기한, 열람권별 재고, 메뉴 (포인트 내역 / 내가 쓴 리뷰 / 프로필 수정 / 회원 탈퇴). 사이드바 재고는 정보만 표시하며 사용은 교환센터에서 진행.
- 포인트 내역 (획득/사용 리스트)
- 내가 쓴 리뷰 목록
  - **빈 상태:** 작성한 리뷰 없을 때 → "아직 작성한 리뷰가 없어요" + 근장 찾기 버튼
- 프로필 수정 **(구현됨)**
  - 수정 가능: 거주지역·입학연도·학위과정·학년·학적상태 (드롭다운). 저장은 `update_profile` RPC → AuthContext 즉시 반영.
  - 소속학교는 **읽기전용** 표시.
  - (추후 아이디어) 1학기에 1번 학년 변경 등 확인 팝업.
- 탈퇴 버튼 (placeholder)

  - 신고 횟수, 작성 리뷰 목록, 처리 버튼 (경고/정지/무시)

## 화면 전환 (상태 기반)

```
비로그인
  └─ 홈 → 로그인 홈과 유사한 공개 큐레이션/공지 레이아웃 표시
  └─ 개인화 추천 섹션은 표시하지 않음
  └─ 근장명, 위치, 태그, 공지 제목은 표시
  └─ 추천 점수, 리뷰 수, 리뷰 내용은 "-"로 숨김
  └─ 검색/필터/카드/공지/상단 탭 클릭 시 로그인 화면으로 이동
  └─ 회원가입 버튼은 회원가입 화면으로 이동

로그인 + 열람권 없음
  └─ 근장 찾기 → 업무·자기계발·분위기·시간유연성 점수와 추천 점수는 잠금 플레이스홀더, 리뷰 수와 추천율 문장은 표시
  └─ 근장 상세 → 업무·자기계발·분위기·시간유연성 점수와 추천 점수는 잠금 플레이스홀더, 리뷰 수와 추천율 문장은 표시, 리뷰 목록은 잠금 플레이스홀더
  └─ "열람권이 필요해요 → 리뷰 작성하기 / 광고 보기" 안내

로그인 + 열람권 있음
  └─ 근장 찾기 → 평점·리뷰 전체 표시
  └─ 근장 상세 → 평점 요약 + 리뷰 전체 열람

로그인 + 이번 학기 리뷰 이미 작성
  └─ 리뷰 작성 버튼 비활성화 + "이번 학기 작성 완료" 표시

```
