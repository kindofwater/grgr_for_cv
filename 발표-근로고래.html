MVP — 근로장학생을 위한 근무지 리뷰·추천 서비스

무엇을 만들었나

  • 전국 근로장학 근무지 6,700+를 검색·비교하는 웹서비스 (grgr.kr)
  • 실제 근무 경험 리뷰 5개 항목 별점(업무량·자기계발·분위기·시간유연성·추천)
  • 포인트 · 열람권 경제 — 리뷰 쓰면 적립, 열람권으로 리뷰 열람
  • 광고 시청 리워드 · 공지 · 마이페이지 · 회원탈퇴까지 서비스 전체 사이클

어떻게 만들었나

  • React + Vite 프론트 · Supabase(Postgres · Auth · RLS)
  • 별도 백엔드 서버 없이 RPC + Row Level Security로 보안
  • Cloudflare Pages 자동배포 (main=개발 / prod=실서비스)
  • 장학재단·학교 포털 크롤러로 근무지 데이터 적재

로그인 · 근장찾기 — 현수

학교 이메일 OTP 인증으로 가입(고려대·서울대) → 3단계 프로필 마법사. 근장찾기는 검색·정렬·페이징 전부 서버 처리, 고급검색 패널로 유형·교내외·지역·근무기간·지원자격을 조합 필터.

리뷰 쓰기 — 유진

근무 경험을 5개 항목 별점 + 서술로 기록. 익명 옵션(닉네임·근로학기 숨김), 학기당 1리뷰 제한, 리뷰 작성 시 포인트 적립(일반 15p / 익명 5p) — 삭제·익명 전환 시 차액 회수까지 정책화.

홈 · 근장상세 · 교환센터 — 경록

홈은 프로필 기반 맞춤 추천 + 비로그인도 둘러보기 개방. 근장상세는 점수 요약·리뷰·공고 정보를 조립. 교환센터에서 포인트 ↔ 열람권 교환, 광고 시청(일 2회)으로 적립 — 수익화 실험까지.
